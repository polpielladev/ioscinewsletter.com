### [​​🤖 Safari now has an MCP!](https://webkit.org/blog/18136/introducing-the-safari-mcp-server-for-web-developers?utm_source=ioscinewsletter&utm_medium=web&utm_campaign=issue_90)

This one is not strictly CI/CD, but it felt too relevant to developer tooling and agents not to include. Safari Technology Preview 247 now includes an MCP server that lets compatible agents inspect and interact with a Safari browser window.

That means your agents can access things like the DOM, console logs, network requests, screenshots, and page interactions directly from Safari. This is great news, and another sign that Apple is truly investing in providing the best tools for agentic development in Apple platforms!

### [☁️ How to set a custom build number for your builds in Xcode Cloud](https://antongubarenko.substack.com/p/swift-bits-xcode-cloud-build-number?utm_source=ioscinewsletter&utm_medium=web&utm_campaign=issue_90)

By default, Xcode Cloud will automatically start at build number one and continuously increment it for each build you deploy to TestFlight. This is great for new projects, but if you already have TestFlight builds for your app and are migrating to Xcode Cloud, it might not work for you.

Thankfully, and as [Anton](https://x.com/AntonGubarenko) explains in this short post, the answer isn't to keep submitting builds until you get to the number you want. Instead, you can set a custom build number for your builds in Xcode Cloud.

### [🧐 What you need to know about Git LFS](https://www.scottberrevoets.com/2026/07/01/how-github-handles-git-lfs?utm_source=ioscinewsletter&utm_medium=web&utm_campaign=issue_90)

Snapshot tests are great, but they often leave teams with a lot of image files to store somewhere. Git LFS can look like the obvious answer, but as [Scott Berrevoets](https://www.linkedin.com/in/sberrevoets) explains in this post, there are some important GitHub-specific details to keep in mind.

The main takeaway for me is that Git LFS is not just "Git, but better for big files". Storage, bandwidth, CI clones, deleted files, and history rewrites all have their own trade-offs, and understanding those upfront can save you a lot of pain later.
